# Mapeamento GestãoX → ADO

| GestãoX | Azure DevOps |
|---|---|
| ID | Tag `GestãoX-<id>` e seção Origem |
| Título | `[GestãoX #<id>] <título>` |
| Descrição sanitizada | Contexto |
| URL | Link de origem |
| Evidências técnicas | Comentário ou critérios de aceite |
| Status | Não mapear automaticamente; os ciclos de vida são diferentes |
| Solicitante | Contexto, somente quando necessário |
| Responsável de atendimento | Não presumir como responsável de desenvolvimento |

Preferir `Task` para uma correção granular. Criar `Projetos` somente quando o chamado revela uma iniciativa completa e o usuário fornece JTBD, contexto e objetivos.
