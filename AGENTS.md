# GestãoX Atendimento

- Use native PowerShell, Node.js and npm commands. RTK is disabled by Defender ASR.
- Run `npm test` from `server/` before changing behavior.
- Never persist passwords, tokens, cookies, personal data, or ticket attachments in source control.
- Keep reads and writes separate. Every remote write requires `confirmed=true` and an idempotency key.
- Do not invent GestãoX routes. Record only routes observed in vendor documentation or an authorized session.
- Keep Azure DevOps creation as a preview until the user explicitly confirms it.
